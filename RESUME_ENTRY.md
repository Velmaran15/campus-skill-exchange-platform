# Resume Project Entry — Campus Skill Exchange Platform (SkillX)

## Project Summary

**Campus Skill Exchange Platform (SkillX)** — A peer-to-peer skill-sharing platform for campus students that enables students to register as tutors or learners, list skills they want to teach or learn, request and manage tutoring sessions, and chat in real time with file attachments.

**Technologies:** React, TypeScript, Vite, Node.js, Express, MongoDB, Socket.IO, JWT, Tailwind CSS, Zustand, Axios, Multer, Nodemailer.

**GitHub:** https://github.com/Velmaran15/campus-skill-exchange-platform

**Live Demo:** [To be added after deployment]

## Resume Bullets

- Developed a peer-to-peer campus skill-sharing platform (SkillX) with skill discovery, session requests, and real-time messaging
- Implemented JWT-based authentication with role-based access control (tutor/learner) and secure password hashing
- Built real-time chat with Socket.IO including participant-only room access, JWT-authenticated connections, and file attachments
- Integrated email notifications via Nodemailer for registration and session updates
- Designed responsive frontend with React 18, TypeScript, Vite, Tailwind CSS, and Zustand state management
- Configured production-ready backend with Express 5, MongoDB/Mongoose, CORS, and environment-variable-driven configuration
- Enabled file uploads with Multer for profile images and chat attachments
